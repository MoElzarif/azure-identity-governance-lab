# 02 — Microsoft Entra Users and Groups

## Objective
Model role-based team access with identities and security groups.

## Evidence
The screenshots show four users and three cloud security groups: **SG-CloudOps**, **SG-Engineering**, and **SG-Security**. Each group has one member shown in the corresponding membership screenshot.

## Procedure
1. Navigate to **Microsoft Entra ID > Users** and create lab identities.
2. Create the three assigned-membership security groups under **Groups**.
3. Add members according to team responsibilities.
4. Review the users, groups, and direct-members lists.

**Why it matters:** Assigning access to groups is easier to audit and maintain than granting permissions to each person individually.
