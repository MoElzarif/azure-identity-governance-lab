# 04 — Security Defaults and MFA

## Objective
Strengthen sign-in security for the lab identities.

## Evidence
- Microsoft Entra **Security defaults** are shown as enabled.
- A lab identity's security-info page shows **Microsoft Authenticator** registered as a push MFA method.

## Procedure
1. Review tenant security defaults in Entra settings.
2. Confirm security defaults are enabled.
3. Register Microsoft Authenticator for the test account.
4. Review the security-info page and related sign-in records.

**Validation note:** Registration proves the method was configured for the pictured identity; it does not independently prove that every account completed MFA for every sign-in.
